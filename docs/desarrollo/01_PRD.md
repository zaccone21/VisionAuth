# Product Requirements Document

## Propósito

Construir un sistema de autenticación por presencia priorizando
comodidad sobre seguridad de nivel empresarial.

## Objetivos

-   Reconocer usuarios registrados.
-   Mantener bajo consumo.
-   Activar la cámara solo cuando sea necesario.
-   Integrarse posteriormente con Windows Services.

## Fuera de alcance (v1)

-   Reemplazar Windows Hello.
-   Credential Provider nativo.
-   Interfaz gráfica.

## Casos de uso

1.  Registrar usuario.
2.  Detectar presencia.
3.  Reconocer rostro.
4.  Emitir AUTH_SUCCESS.
